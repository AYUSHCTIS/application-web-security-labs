# Application and Web Security Labs

Course lab presentations for **Application and Web Security**. Educational use only.

## About

Lab slide decks covering an isolated malware-analysis sandbox, offline Windows SAM inspection with Kali in forensic mode, and dynamic analysis with x64dbg. Built for university coursework. No malware samples are included in this repository.

## Labs

| File | Lab | Topics |
| --- | --- | --- |
| [Lab 4 — malware sandbox](Application%20and%20websecurity%20EXP-4.pptx) | Lab 4 | VirtualBox, FlareVM, REMnux, INetSim |
| [Lab 7 — Kali SAM lab](Application%20and%20websecurity%20exp%20-%207.pptx) | Lab 7 | Kali live (forensic mode), SAM inspection |
| [x64dbg analysis](Step-by-step%20Malware%20Analysis%20Using%20x64dbg.pptx) | Extra | x64dbg, Detect It Easy |

## How to use

1. Clone or download this repository.
2. Open the `.pptx` files in PowerPoint or LibreOffice.
3. Run any lab steps only on machines you own or that your instructor approved.

## Disclaimer

These materials are for authorized classroom and lab environments only.  
Do not use the procedures against systems you do not own or do not have written permission to test.
